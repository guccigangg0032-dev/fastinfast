# Fast Insurance Online

Адаптивный одностраничный сайт проекта **Fast Insurance Online** (Казахстан). Размещён в \`guccigangg0032-dev/fastinfast\`.

## Состав

- \`index.html\` — контент и структура главной страницы.
- \`styles.css\` — дизайн и адаптивная сетка.
- \`app.js\` — мобильное меню, подготовка обращения, копирование текста.
- \`favicon.svg\` — векторная иконка.

Работает на статическом хостинге без сборки, внешних JavaScript-библиотек и базы данных. Шрифты Google Fonts опциональны: без интернета используются системные.

## Запуск и размещение

Откройте \`index.html\` в браузере или разверните каталог на любом статическом хостинге. Для проекта выбран домен **https://preview.asia/**. В корне репозитория есть файл `CNAME` со значением `preview.asia`. DNS уже указывает на GitHub Pages, но владельцу нужно включить публикацию в Settings → Pages → Deploy from a branch → main → / (root), затем проверить SSL/HTTPS в GitHub Pages. Изменения DNS для других сайтов не требуются.

## Статус формы

Форма **не отправляет данные** и **не создаёт полисы**. При подтверждении она формирует текст обращения локально в браузере и даёт скопировать его. Поля: имя, телефон, тип страховки, город (необязательно), вопрос (необязательно). ИИН, документы, банковские данные и фото не запрашиваются.

Для перехода через WhatsApp после согласования юридических документов:

1. Укажите подтверждённый номер бизнеса в \`app.js\` → \`whatsappNumber\` в международном формате без \`+\`.
2. Обновите описание согласия на обработку данных и политику конфиденциальности под реальные условия обработки/передачи в WhatsApp.
3. Проверьте ссылку на WhatsApp и ручную отправку на мобильном и компьютере.

Альтернативно в \`app.js\` можно указать \`publicEmail\`, и браузер предложит открыть почтовое приложение. Для настоящего автоматического приёма заявок необходимы защищённый backend/CRM, проверка согласий, контроль доступа, защита от спама и юридическая документация. **Не храните API-ключи в файлах сайта.**

## Перед публичным запуском

- Уточнить, кто юридически является оператором: ИП/ТОО, реквизиты, БИН/ИИН (в публичных реквизитах по необходимости), адрес и контакты.
- Проверить договоры со страховщиками, допустимые продукты и порядок оказания услуг. **Посредничество страховых агентов при заключении обязательного автострахования ОГПО регулируется ограничениями**, поэтому нельзя обещать агентское онлайн-оформление ОГПО.
- Подготовить правовые основания для обработки персональных данных, политику конфиденциальности и условия сервиса с учётом законодательства РК.
- Подключать получение премий, биометрию и выпуск электронных полисов **только после юридической проверки и официальных интеграций со страховщиками**.
- Протестировать доступность интерфейса, копирование и мобильное меню; заменить демонстрационные описания реальными подтверждёнными данными.
